A trading gateway has a few microseconds from packet to order. A bedside monitor must raise its alarm within a bounded time, every time, for years. A PET scanner streams millions of detector events a second and may not lose one without saying so. A mutex and a standard container will not get you there. Knowing what the cache, the memory model and the scheduler really do will.

The Nanosecond Budget builds every structure from scratch in C++20, explains it line by line, tests it under ThreadSanitizer and measures it with a harness that tells the truth about tail latency. You will learn to read latency as a distribution and measure p99.9 without fooling yourself; use the C++ memory model, atomics and release/acquire with confidence; build spinlocks, seqlocks, SPSC rings, MPMC queues and a Disruptor-style broadcast ring; take malloc off the hot path and reclaim memory safely with hazard pointers and epochs; design concurrent hash maps, skip lists and order books; tune Linux for low jitter and verify concurrent code with sanitizers and model checking; and apply it all to a real-time PET data-acquisition pipeline with coincidence sorting.

A compact Foundations part refreshes the modern C++ and threading the rest of the book relies on. Every chapter ends with exercises, all solved in full, and the book comes with llds, a complete header-only companion library with tests and benchmarks.
